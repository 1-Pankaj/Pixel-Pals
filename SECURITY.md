# Security Policy

## Supported Versions

Security updates are provided for the latest minor release branch:

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or security bug in Pixel Pals, please report it privately:

1. Do **not** open a public issue.
2. Report via GitHub's private vulnerability reporting feature (under the **Security** tab of the repository -> **Report a vulnerability**), or contact the maintainers directly.
3. Include:
   - A clear description of the vulnerability.
   - Exact steps or script to reproduce the issue.
   - Operating system and Electron/Node version.
   - Potential impact or attack scenario.

### What to Expect
- Maintainers will acknowledge receipt within 48 hours.
- A fix will be developed and verified across supported platforms.
- A patched release will be published alongside a security advisory acknowledging your contribution (unless you prefer anonymity).
